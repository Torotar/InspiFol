PinCase

HARMONYOS 灵感整理应用

把喜欢的灵感，整理成自己的画板

PinCase 是一款面向 HarmonyOS 手机和平板的 Pinterest 灵感整理应用。它把灵感发现、Pin 详情查看、收藏和画板管理放在一个清晰的使用流程中，帮助你为项目、兴趣和日常想法建立自己的灵感空间。PinCase 是 Pinterest 第三方应用，不代表 Pinterest。

从发现一张喜欢的图片开始：查看 Pin 详情，保存到本地画板；完成 Pinterest 授权后，也可以按授权范围读取账号、Pin 和画板，并发起相应的整理操作。

核心功能

  • 浏览首页和发现内容，按主题和推荐找到值得收藏的视觉灵感。
  • 搜索并打开 Pin 详情，查看图片、标题、描述、来源和相关内容。
  • 把喜欢的 Pin 保存到本地画板，创建画板并按项目或主题整理收藏。
  • 在手机和平板上回看画板，通过系统分享把灵感发送给需要的人。

一条清晰的使用流程

发现

从首页、发现或搜索开始，找到与项目或兴趣相关的视觉内容。

查看与筛选

打开 Pin 详情，了解图片、标题、描述和来源，再决定是否保存。

收藏、整理与分享

保存到本地画板；完成 Pinterest 授权后，可在授权范围内使用云端画板进行整理，随时回看并分享。

Pinterest API 的适用方式

只有在用户主动登录 Pinterest 并同意相应权限后，PinCase 才会通过 OAuth 2.0 获取访问授权，并通过已配置的网关调用 Pinterest 官方 API。授权请求包含 boards:read、boards:write、pins:read、pins:write 和 user_accounts:read；在授权范围内，应用可读取账号信息、Pins 和画板，创建画板，将用户选择的 Pins 保存到画板，并执行授权范围内的账号关系和 Pin 操作。API 返回数据只用于用户主动请求的浏览、详情展示、收藏和画板整理。PinCase 不读取无关内容、不出售 Pinterest 数据，也不将其用于广告画像。

账号与数据

登录 Pinterest 后，OAuth 凭据保存在设备安全资产中。本地画板和收藏记录保存在设备上；应用通过已配置的网关，在授权范围内访问 Pinterest 账号、画板和 Pin 接口。用户可在应用内退出登录并清除本地登录凭据；删除应用或清除应用数据会删除本机画板和收藏记录。云端 Pinterest 数据仍由用户在 Pinterest 账户中管理。
