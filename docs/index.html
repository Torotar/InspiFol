PinCase

HARMONYOS THIRD-PARTY CLIENT PROTOTYPE

发现、整理和保存视觉灵感

PinCase 由李栋强开发，面向希望在 HarmonyOS 手机或平板上整理 Pinterest 灵感的个人用户。PinCase 不是 Pinterest 官方应用，也不代表 Pinterest。

当前版本同时包含本地原型界面和受控的 Pinterest API 验证入口。内容 feed、评论、通知、图片上传和发布服务仍未接入。

应用功能

  • 浏览首页、发现、通知和个人页面。
  • 在设备本地创建画板、保存灵感标识并管理收藏。
  • 在配置网关和授权后，通过 Pinterest OAuth 2.0 + PKCE 登录，读取账号资料和云端画板。
  • 在授权范围内读取 Pin，并创建公开或私密 Pinterest 画板、收藏 Pin。

如何使用 Pinterest 内容

用户主动登录或在设置中输入短期 access token 后，PinCase 才会请求 Pinterest API。应用仅把返回的 Pin、账号资料和画板字段用于当前页面展示及用户发起的保存操作，不抓取无关内容，也不出售 Pinterest 数据。

账号与数据

未登录时，画板名称、收藏 Pin ID 和排序设置仅保存在本机。登录 Pinterest 后，OAuth 凭据保存在设备安全资产中；应用通过已配置的网关访问 Pinterest 账号、画板和 Pin 接口。用户可在应用内退出登录，清除本地登录凭据；删除应用或清除应用数据会删除本机画板和收藏记录。云端 Pinterest 数据的删除仍由用户在 Pinterest 账户中管理。
