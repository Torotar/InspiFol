# PinCase public site

This directory is the public app description and privacy policy for GitHub Pages.
After enabling Pages for the repository, the expected URLs are:

- `https://torotar.github.io/PinCase/`
- `https://torotar.github.io/PinCase/privacy.html`

The Pinterest developer dashboard must use the deployed HTTPS privacy URL. A
GitHub repository URL alone is not a substitute for the live site.
